# Frontend

TypeScript, React, ViteによるWeb UIを配置する.
バックエンド接続前は`src/mocks`のデータを使用し, フリック操作と閲覧体験を優先して開発する.

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで表示されたURLを開く.

## 操作

- カードを左へフリック: スキップして既読にする
- カードを右へフリック: あとで読むに保存
- カード左上のゴミ箱ボタン: 削除記事一覧へ移動
- カード右上の星ボタン: お気に入りを切り替える
- 左右の矢印キー: フリックと同じ操作
- Enterキーまたは「記事を読む」: ダミー記事の詳細を表示

通常の記事列には, 未読かつ「あとで見る」と削除記事一覧に入っていない記事だけを表示する.
状態はブラウザの`localStorage`へ保存する.
「スキップした記事を戻す」ではスキップ由来の既読だけを解除し, 保存記事と削除記事には影響させない.
削除記事は削除記事一覧から個別に戻す.

各一覧は独立したページとして表示し, ハッシュURLで切り替える.

- お気に入り: `#/favorites`
- あとで見る: `#/saved`
- 削除記事: `#/deleted`
- タグ管理: `#/tags`
- ニュースソース管理: `#/sources`

タグ管理ページでは, モックタグの追加, 名前変更, 削除ができる.
1つのRSS・Atomニュースソースに複数のタグを割り当てられ, 割り当て操作はニュースソース管理ページで行う.
タグを削除してもニュースソースと記事は削除せず, 削除したタグの割り当てだけを解除する.
タグと割り当てはブラウザの`localStorage`へ保存する.
ニュースソース管理ページでは, RSS・Atomソースの追加, 取得の有効・停止, タグの割り当て, 削除ができる.
RSS・Atomの形式はユーザーが指定せず, フィードの取得内容から自動判定する.
各ソースには選択済みタグだけを表示し, プラスボタンからタグ一覧を開いて複数選択する.
現在の取得状態はモックであり, 実際のフィード取得はバックエンド接続後に実装する.

カード本文は文字数で切り詰めず, 提供された要約と本文をすべて表示する.
文章がカードの高さを超える場合は, カード本文を縦スクロールして読む.
縦方向の操作はカード本文のスクロールに使用する.

記事カード左側では, 「ニュースソース」または「タグ」のどちらか一方を選んで記事を絞り込める.
ニュースソースとタグの条件は同時適用しない.
モバイルでは同じ選択欄を記事カード上部へ表示する.

ヘッダーのハンバーガーメニューから, ソース, タグ, お気に入り, あとで見る, ゴミ箱へ移動できる.
